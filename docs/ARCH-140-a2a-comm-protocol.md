# ARCH-140 · Agent↔Agent 通讯协议（a2a comm）—— 新模型「就是普通消息」

> **类型**：ARCH（讲它怎么运转）· band 1xx = feishu 桥
> **职责**：定义**智能体之间**怎么经飞书桥对话。
> **与 [`ARCH-110`](ARCH-110-feishu-bridge.md) 的分工**：ARCH-110 = 桥本体（@bot→注入 / hook→outbox→drainer 回传 / 多 bot）；**本档 = 架在桥之上的「agent 之间怎么对话」那一层**。
>
> **🔄 2026-07-02 大简化（主人定）**：**删掉整套「守望 / reply-wait / --wait / 轮询 / 超时 / 防回环哨兵」。a2a 就当普通消息收发。** 下文即新模型；旧的「reply-wait 守望 + 哨兵丢弃」已废（见 §2 演进）。

---

## §1 · 一句话模型

**agent↔agent 的对话都在一个共享【群】里，就当【普通消息】收发：**
- **发**：`send_feishu_msg --to-agent B` → 发到共享群、@B、盖 `[飞书_from_A_to_B]` 戳。**发完即返回**（不守望）。
- **收（对方派活给我）**：B 的桥收到「@B 的群消息」→ **注入 B 的会话**（当普通消息）→ B 处理、回复（回复经 drainer 发回群 @A）。
- **收（对方的回信回到发起方）**：A 的桥收到「@A 的群消息」（= B 的回信）→ **注入 A 的会话** → A 处理，自己判断要不要接着聊。
- **没有守望、没有 --wait、没有轮询、没有哨兵、没有机械防回环。** 发就完了，回信自然会来（桥投进你会话）。

> 对照：**主人↔bot = 私聊 DM（route=p2a）**；**agent↔agent = 群（route=a2a）**。群 = `shared_group(A,B)` 现解析（`oc_…` 不硬编码）。

## §2 · 为什么这么简单（演进 · 别再走回头路）

- **旧模型**：桥收到对端回信（尾缀隐形哨兵 `PEER_LOOP_MARK`）→ **扔掉**（防 A@B→B@A→…死循环）；发起方靠 `--wait` **主动守望**（轮询群、等结构化裁决 done/blocked/failed）才收得到。
- **旧模型的洞（2026-07-02 实证）**：**不守望就收不到** —— 发起方一旦 fire-and-forget（没传 --wait，或判断"不急"没守望），对端回信落群、桥把它扔了、没人接（实测：tb24-link16 回信 @ tb25-link16，tb25-link16 没守望 → 收不到）。
- **新模型**：桥**不再扔** —— 把「@我的群消息（含回信）」**当普通消息投进我会话**。⇒ 收到的「保证」从**「发起方记得守望」**（能忘、能跳过）搬到**「桥自动投递」**（永远在线·跳不过）。这才是真·必达。
- **防回环（2026-07-02→07-03 更正）**：07-02 曾赌「不机械防·靠 agent 自识别终止·真撞上再加保险丝」。**07-03 就撞上了**：tb24-notes-2 ↔ tb25-tennis-post 空转 **160 条**（80 来回·全是 `.`/`Standing by`/`(Silent.)`·🔧0💭0）。根因：桥**无条件路由** agent 每轮输出 + **零熔断**；agent 想沉默但 harness 催「产出可见输出」→ 退发「.」，而「.」就是燃料。⇒ **保险丝现在补上了**（见 [§2.5](#25-·防回环结束工具--空转熔断)）。**「靠 agent 自识别终止」被证不足以承重**（agent 能*察觉*loop、却没有*干净的停止动作*）。

## §2.5 · 防回环：结束工具（主动）+ 空转熔断（兜底）

**分层，越底层越不靠 agent：**

**① 结束工具（主力·on-demand·agent 主动）** —— `feishu/a2a_end.py`
agent 察觉「在空转 / 没实质内容」→ 调它 → 落**静音标志**（`bridge-a2a-mute-<bot>.json`，keyed by peer **open_id**）。桥 `on_message` **注入前先查标志**：该 peer 已静音 → **不注入**（连会话都不唤醒＝零烧钱），loop 断。这是给 agent 的**离散停止动作**（对照旧「靠少吐字沉默」——那被 harness 逼着还会吐「.」）。零参调用＝静音**当前 a2a 对手**（桥每条 a2a 写 `bridge-a2a-lastpeer-<bot>.json`，工具读它）。

**② 空转熔断（兜底·纯代码·不靠 agent）** —— 桥 `on_message` 内计数
对「同一 peer（keyed open_id）连续【空转】a2a 消息」计数，**连续 N=4** → 落同一静音标志 + 给 owner DM 报**一条**。
- **空转判据（机械·确定性·两条【零误伤】·2026-07-03 单测定死）**：剥掉 @ 和 footer 后，① **无内容**＝正文没有任何词字符（纯标点/emoji·`.` `。` `…` `👀`），**或** ② **重复**＝与该 peer **最近 3 条**正文 norm 后相等（`(Silent.)` 刷屏 / `Standing by.` 连发）。
  - **为什么不用「长度阈值」**：`≤15 字符` 会误砍**简短但新颖**的真实消息（`20` / `A吧` / `调到 24px` —— 实证：一段全短消息的有效对话会被 ≤15 判成 4 连空转误熔断）。长度分不清「简短实质」vs「空转」；**无词字符 + 重复**才零误伤。
- **计数器遇「有营养的消息」清零**（有词字符 且 不与近 3 条重复）＝ **有效对话永不误伤（含简短对话）**：任何一条新颖实质内容都归零，熔断只砍得动**连续的空/重复**，而砍空**无损**（那几条本就是 `.`）。所以 N 可以设小（4），零风险。
- **真人**：真人消息通常实质 → 走「清零」路径；且真人 open_id ≠ peer bot、不进该 peer 计数。无需单独判「人 vs bot」。

**③ 熔断＝永久静音（无冷却·无自动解封·主人 2026-07-03 定）**
一旦静音就**晾着**（两面板闲置），**不自动恢复**。要重启对话由**主人手动**：桥 slash `/a2a-unmute [peer]`（或删 `bridge-a2a-mute-<bot>.json`）。静音标志**落文件、跨桥重启存活**（重启不重开已知坏 loop）。

**为什么 robust**：三层递降、越底层越不靠 agent——agent 配合→①干净断；agent 摆烂→②纯代码在收侧拦（连续空转必被数到）；命门不压在「agent 写对信号」上。**闸门唯一在收侧**（`on_message` 注入前）：不注入→无 turn→无回复→出侧自然停，不必改 drainer。

## §3 · 结构化信号（判定只认这些）

| 信号 | 含义 |
|---|---|
| `[飞书_from_<发>_to_<收>]` 戳 | 发信方**自盖·带名字**（`send_feishu_msg` 盖）。飞书 SDK 事件给的 `open_id` 按 app 隔离、认不出名 → **这个戳才是「谁发的」的 SSOT**。桥注入信封的 `from=` 解它（`feishu_bridge.a2a_from_name`）。 |
| `msg_type == "text"` | 实质内容。**a2a 必走纯文字**——飞书把收到的卡片渲成占位 `[interactive]`，对端 bot 读不到正文。 |

## §4 · 工具原语（三个·全在 `feishu/`）

| 原语 | 谁用 | 职责 | 工具 |
|---|---|---|---|
| **send** | 发起方 | 发到共享群、@对方、盖 from 戳。发完即返回（回信桥自动投回我会话） | `send_feishu_msg.py --to-agent B --text "…"` |
| **read**（兜底手动读群） | 任何人 | 一步读【群】recent、抽 a2a 回合 | `bridge_feishu_probe.py --bot A --group --recent N` |
| **end**（停止对话·防空转） | 任何一方 | 察觉在空转/没实质内容 → 静音当前 a2a 对手（桥停止注入它的群消息、loop 断） | `a2a_end.py`（零参＝静音当前对手；`--peer <名>` 指定；`--status` 看已静音） |

> 被动收（对方 @ 我 → 桥注入我会话 → 我回）= 桥自动做，不需要任何工具/守望。
>
> **a2a 行为规范（agent 必读）**：**收到 ≠ 必须回**。没有实质内容要说、或发现你俩在**空转**（反复 `.`/`收到`/`Standing by` 这类空回复）→ **调 `a2a_end.py` 停，别再发「.」**——你的任何输出（哪怕一个「.」）都会被桥当消息路由回群、把对面再点着，那正是死循环的燃料。真有事要说才回，聊完就停。

## §5 · 不变量 / 红线

1. **读/发都走共享群**（`shared_group` 现解析·**禁**硬编码 `oc_`/`ou_`·禁绕 DM/对端 outbox）。
2. **a2a 必走纯文字**（卡片对端读不到）。
3. **桥把「@我的群消息」当普通消息注入**——不扔、不特殊守望、不加哨兵。这是「必达」的地基（桥永远在线）。
4. **防回环＝结束工具 + 空转熔断**（[§2.5](#25-·防回环结束工具--空转熔断)）：agent 主动 `a2a_end` 为主，桥「连续 4 空转自动熔断」兜底；熔断＝**永久静音**（无自动解封·主人手动 `/a2a-unmute`）。**不再赌「纯靠 agent 自识别」**（07-03 空转 160 条实证不足以承重）。
