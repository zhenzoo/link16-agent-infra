## 方案与验收

复用 bridge_injection.ProcessFileLock 的操作系统文件锁；服务持有到退出，控制命令另持事务锁。进程查询统一为带成功标记及合法 schema 的快照，PowerShell 使用 ErrorAction Stop；失败为 unknown，禁止转为空表。run 不杀其他服务实例，start 在事务锁内进行已知旧实例的受控替换。查询未知不停止、不启动；停止等待目标进程退出后才报告成功。整体停止先验证所有查询，再停桥，最后停守护。

R4 仅在确认通知成功后置位。R6 仅在确认通知成功后推进 seen，通知冷却只记录成功；写状态时保留通知函数更新的字段。心跳暴露巡检失败，进程活不能代替功能健康。

验收包含三种独立路径：失败/schema 注入，真实多进程互斥及异常退出释放，真实 PowerShell 查询与无害进程停止；再运行全仓回归。故障通知全部隔离，不向主人发假告警。生产更新先本机后其他机器，确认版本、服务唯一性、新鲜心跳、R6 不再新增及真实回信。
